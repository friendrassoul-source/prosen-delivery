# PROSEN Delivery V13.4 — Livraison à la demande

Cette version retire complètement le catalogue et le panier. PROSEN est une application de mise en relation client/livreur.

## Démo sans configuration
- Ouvrir `public/index.html` directement dans Chrome pour tester l'interface.
- Ou lancer `START.bat` après `npm install` puis ouvrir http://localhost:3000.

## Parcours client
Départ → destination → détails colis → estimation → recherche livreur → livreur trouvé → colis récupéré → en livraison → livraison terminée → paiement direct au livreur.

## Parcours livreur
Hors ligne → en ligne → course disponible → accepter → récupérer colis → livrer → paiement reçu.

Les paiements sont simulés dans cette démo. Aucun argent réel n'est transféré.
